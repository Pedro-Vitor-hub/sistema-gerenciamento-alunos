# Sistema de Gerenciamento de Alunos

Projeto desenvolvido em Java para praticar e aplicar conhecimentos de programação através da criação de um sistema simples de gerenciamento de alunos.

O sistema permite cadastrar, consultar, atualizar e remover alunos, além de realizar algumas operações como cálculo da média da turma e geração de relatório.

## Funcionalidades

- Cadastro de alunos
- Consulta de alunos
- Atualização de dados
- Remoção de alunos
- Listagem de alunos por nome
- Listagem de alunos por nota
- Separação entre aprovados e reprovados
- Cálculo da média da turma
- Geração de relatório
- Validação dos dados cadastrados
- Tratamento de erros

## Tecnologias

- Java
- IntelliJ IDEA
